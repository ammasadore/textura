# MGShaders Go — Minecraft Bedrock

Pack visual baseado no sistema **Vibrant Visuals/PBR** do Minecraft Bedrock.

### Visual desejado
- Iluminação quente durante o dia
- Lua com luz azul suave
- Contraste e saturação cinematográficos
- Realce de sombras e highlights
- Base preparada para PBR

### Compatibilidade
O pack usa a capability `pbr` e requer uma versão do Bedrock compatível com Vibrant Visuals. A documentação oficial indica `min_engine_version` 1.21.120 ou superior para packs Vibrant Visuals.

Depois de importar o pack, ative **Configurações → Vídeo → Modo Gráfico → Vibrant Visuals**, se essa opção estiver disponível no seu dispositivo.
