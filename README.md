# FPS Boost 16x — Minecraft Java

Resource pack leve focado em desempenho.

## Objetivo
- Visual 16x/minimalista.
- Partículas reduzidas/ocultadas quando possível pelo resource pack.
- Animações de texturas de água e lava desativadas por substituição das texturas animadas.
- Animações visuais desnecessárias reduzidas.
- Sem shaders ou efeitos pesados.

> Observação: um resource pack sozinho não consegue desligar todas as partículas ou todas as animações do Minecraft. O que depende de configurações do jogo/mods precisa ser desativado nas opções ou por mods de otimização.
